## 一、先建立一张行业地图

### 1. 行业走到哪一步了？

过去几年，中国新能源汽车完成了从「补贴驱动」到「产品与供应链驱动」的跨越：

- **规模**：2025 年中国汽车产销约 **3450 万辆** 量级，连续多年全球第一；其中新能源汽车产销均超过 **1600 万辆**，新车渗透率接近 **48%**，部分月份国内零售占比已 **连续突破 50%**。
- **竞争阶段变化**：早期拼「能不能量产、有没有牌照」，中期拼「月销过万、渠道下沉」，到 2025–2026 年更像一场 **能力验证赛**——智能化落地速度、供应链健康度、单车盈利、海外本地化，比单纯堆销量更重要。
- **价格与利润**：「价格战」压低了行业均价（乘用车均价从二十万出头继续下探），整车行业利润率从高峰时的 6% 左右，一度压到 **4% 出头** 的水平。许多环节呈现 **增收不增利**。
- **格局**：「新势力」不再是理想一家独大。零跑等凭借性价比与渠道合作放量；小鹏、小米销量上了 **40 万辆** 台阶；理想在竞争加剧后销量承压；蔚来靠多品牌（蔚来 / 乐道 / 萤火虫）稳住增长。与此同时，**比亚迪等传统自主** 与 **华为智选车（鸿蒙智行）** 在销量与话语权上同样不可忽视；全球纯电销量维度上，中国品牌整体已对特斯拉形成强力冲击。

一句话概括：**电动化「量变」大体完成，智能化与盈利质量进入「质变」窗口。**

### 2. 上下游供应链：钱和风险都在哪？

可以把新能源乘用车产业链粗分为四层：

| 层级 | 主要环节 | 代表方向 | 商业特征 |
|------|----------|----------|----------|
| **上游资源与材料** | 锂、镍、钴、锰、磷；正极 / 负极 / 隔膜 / 电解液 | 矿企、盐湖、材料厂 | 强周期；价格波动直接决定电池与整车成本 |
| **中游核心部件** | 动力电池、电驱、电控、热管理、车规芯片、域控制器、激光雷达 / 摄像头 | 宁德时代等电池巨头、Tier-1、芯片与传感器公司 | 技术与资本双密集；议价权向头部集中 |
| **整车（主机厂）** | 平台定义、集成、制造、品牌与渠道 | 理想、小鹏、蔚来、小米、特斯拉、比亚迪等 | 拼产品定义、软件、成本与组织效率 |
| **下游与生态** | 销售金融、保险、充电 / 换电、维保、二手车、出行与数据服务 | 经销 / 直营、运营商、能源公司 | 决定用户体验与长期利润池 |

**几个值得单独记住的结构性事实：**

1. **电池是中枢**  
   动力电池往往占整车 BOM 很大一块。头部电池厂通过规模、良率与技术迭代（磷酸铁锂、高镍三元、快充体系、钠电等）掌握议价权；主机厂则通过 **多供应商、自研 PACK / BMS、甚至自建电芯产能** 来对冲。

2. **智能化把「新玩家」拉进传统供应链**  
   激光雷达、高算力 SoC、座舱芯片、地图与云服务，让消费电子、互联网与半导体公司深度嵌入汽车。供应链从「金字塔式配套」变成 **网状生态**——联合开发、数据共享、甚至资本纽带越来越常见。

3. **补能是另一条产业链**  
   - **充电**（慢充 / 超充）：覆盖面广，重资产但模式成熟。  
   - **换电**：蔚来最重，宁德时代等也在推干线与乘用车换电网络。换电能缓解里程焦虑、利于电池梯次利用，但 **站网建设资本开支大、标准尚未完全统一**。

4. **账期与「反内卷」**  
   价格战时期，部分主机厂把压力转嫁给中小供应商（拉长付款账期）。政策层面对大中小企业之间付款周期提出更严约束（行业讨论中常见「不超过 60 天」一类要求），方向是推动供应链从 **成本压榨** 转向 **风险共担**。对做 PE / 研究的人来说：看车企不能只看毛利率，还要看 **对供应商的占用是否可持续**。

### 3. 盈利模式：车企到底靠什么赚钱？

现实中，主流模式往往是 **「硬件是入场券，软件与服务是期权」**，但兑现进度差异很大：

1. **整车销售毛利**（当前主利润源）  
   售价 − 电池 / 材料 / 制造 / 渠道成本。理想等曾靠 **中大型家庭 SUV + 增程** 做出相对健康的单车毛利；走性价比路线的品牌则用薄利换规模。

2. **软件与订阅**  
   智驾订阅、座舱功能包、车联网服务。特斯拉 FSD 叙事最强；中国品牌在城市 NOA、端到端大模型上投入巨大，但 **大规模、高付费率的订阅收入** 仍在爬坡。

3. **能源与补能**  
   充电服务费、换电服务、电池租赁（BaaS）。蔚来换电把「买车」拆成「车 + 电池服务」，改善购车门槛，同时绑定长期现金流——前提是站网利用率够高。

4. **金融与后市场**  
   贷款、保险分润、配件、延保、改装。成熟车企利润结构里这块很重；新势力仍在补齐。

5. **生态交叉补贴**（小米最典型）  
   手机 / IoT / 互联网服务获客与品牌，汽车作为 **高客单价入口**；汽车本身阶段性亏损，由集团其他业务与资产负债表托底。

6. **积分与政策相关收益**（逐渐退潮但未消失）  
   「双积分」下，新能源积分仍有交易价值；购置税减免、以旧换新影响 **终端成交价与销量节奏**，间接影响盈利。

**研究提示**：同一「卖车」动作，理想更像 **高客单家庭耐用品**；小鹏更像 **科技硬件 + 智驾溢价**；蔚来更像 **服务型豪华**；小米更像 **生态型消费品牌**；特斯拉则同时讲 **汽车 + 能源 + AI / 机器人** 的平台故事。估值体系因此完全不同。

### 4. 法律法规与政策环境（2025–2026）

政策已从「大水漫灌补贴」转向 **结构引导 + 规范竞争 + 安全底线**：

| 政策工具 | 要点 | 对行业的影响 |
|----------|------------------|--------------|
| **购置税** | 2024–2025 年新能源乘用车免征（有税额上限）；**2026–2027 年减半征收**（上限更低） | 刺激前移；2026 起政策力度边际减弱，对价格敏感车型影响更大 |
| **以旧换新** | 2026 年报废更新购新能源最高约 **2 万元**；置换更新最高约 **1.5 万元**（按车价比例、设上限） | 拉动换购，利好有现车与渠道执行力的品牌 |
| **双积分** | 新能源积分比例要求继续抬升：如 **2026 年约 48%、2027 年约 58%**（以主管部门正式通知为准） | 倒逼燃油车企电动化；积分富余企业仍有博弈空间 |
| **安全与智驾监管** | 数据安全、网联安全、辅助驾驶宣传规范、事故责任界定趋严 | 限制「过度营销智驾」；研发与合规成本上升 |
| **供应链与反内卷** | 规范付款账期、整治无序价格战等 | 利好优质零部件商，挤压纯靠压价扩张的模式 |
| **出海与贸易** | 欧美关税、本地化生产、碳足迹与电池护照等 | 出口从「整车出海」转向 **本地建厂 + 供应链出海** |

**结论**：政策仍是 **托底与导向**，但企业已不能指望政策单独创造利润；**产品力、成本曲线、海外体系** 才是 2026 之后的主变量。

## 二、主流车企：造车思路与主要受众

下面聚焦用户点名的几家，并带上行业里绕不开的对照系。数字为公开报道量级，用于建立感觉，而非精确对账。

### 1. 理想汽车（Li Auto，美股 LI / 港股 2015）

| 维度 | 内容 |
|------|------|
| **核心思路** | 长期以 **增程式** 解决里程焦虑；产品高度聚焦 **中大型家庭 SUV**（L 系列），强调空间、舒适、冰箱彩电大沙发式体验与「奶爸车」心智 |
| **技术路径** | 增程为主，逐步补齐纯电与智驾；家庭场景下的「确定性」优先于极致运动或极致科技感 |
| **主要受众** | 二三线及核心城市的 **有孩家庭、多成员出行**；对充电便利性敏感、愿为舒适与省心付费 |
| **优势** | 产品定义清晰；曾做出较好的单车毛利与规模盈利示范 |
| **风险** | 赛道拥挤（问界、零跑、小米增程 SUV 等）；纯电转型与智驾认知若落后，心智可能被分流 |

**一句话**：理想卖的是 **「家庭移动第三空间」**，不是赛道玩具。

### 2. 小鹏汽车（XPeng，美股 XPEV / 港股 9868）

| 维度 | 内容 |
|------|------|
| **核心思路** | **智能化（尤其智驾）** 作为品牌锚点；轿车 + SUV 多线布局，强调技术下放与性价比 |
| **技术路径** | 纯电为主；大力投入端到端 / 大模型智驾、机器人等「物理 AI」叙事；积极做海外本地化 |
| **主要受众** | **科技敏感、愿意尝鲜** 的年轻与中产用户；在意辅助驾驶、座舱交互与颜值 |
| **优势** | 智驾品牌心智相对靠前；2025 年交付同比大幅增长，进入更高销量台阶 |
| **风险** | 价格带竞争极烈；销量波动大时毛利与亏损压力明显；技术叙事需持续被交付验证 |

**一句话**：小鹏更像 **「带四个轮子的智能硬件公司」**。

### 3. 蔚来（NIO，美股 NIO / 港股 9866）

| 维度 | 内容 |
|------|------|
| **核心思路** | **高端服务 + 换电补能** 构建差异化；用户运营（NIO House、社群）极重 |
| **品牌矩阵** | **蔚来**（高端）/ **乐道**（家庭大众纯电）/ **萤火虫**（更入门）——用多品牌覆盖价格带 |
| **主要受众** | 原蔚来用户偏 **认同服务与社群的中高净值**；乐道更贴近主流家庭纯电换购 |
| **优势** | 换电站网络与补能体验独特；品牌忠诚度高；多品牌有助于冲量 |
| **风险** | 换电与服务体系 **资本开支高**；长期盈利兑现慢；高端份额被多方挤压 |

**一句话**：蔚来卖的是 **「车 + 能源网络 + 会员式服务」** 的组合。

### 4. 小米汽车（集团港股 1810.HK）

| 维度 | 内容 |
|------|------|
| **核心思路** | 消费电子式 **工业设计 + 人车家生态**；先用爆款建立「小米也能造好车」的信任 |
| **产品心智** | **SU7**：年轻、运动、高颜值纯电轿车，对标「好看的性能电动」人群；后续 SUV（如 YU7 等）与 **增程 SUV** 意在打进更厚的家庭利润池 |
| **主要受众** | 小米生态用户、年轻人、改车 / 颜值党；逐步向家庭用户扩展 |
| **优势** | 品牌声量、互联网运营、供应链议价与软件体验；集团造血能力强于多数纯造车新势力 |
| **风险** | 汽车业务仍可能阶段性承压；手机等主业波动会连带估值；家庭 SUV 赛道已是红海 |

**一句话**：小米 SU7 打的是 **「年轻人的第一台性能电轿」**；增程 / 大 SUV 则是在学理想那套 **家庭利润池**。

### 5. 特斯拉（Tesla，美股 TSLA）

| 维度 | 内容 |
|------|------|
| **核心思路** | 全球平台化生产、直营与超充网络；软件定义汽车；资本市场叙事扩展到 **FSD / Robotaxi / 储能 / 机器人** |
| **中国市场角色** | 仍是纯电标杆与价格战参与者之一，但份额面对中国品牌群攻 |
| **主要受众** | 全球科技早期用户、品牌认同者、对自动驾驶叙事敏感的投资人与车主 |
| **优势** | 规模、品牌、能效与软件迭代；能源业务提供第二条曲线 |
| **风险** | 汽车主业增速放缓时，高估值需靠 AI 叙事支撑；地缘与品牌政治化风险 |

**一句话**：特斯拉在资本眼里不完全是车企，而是 **「AI + 能源平台」**；在车库里它首先仍是一台电动车。

### 6. 快速对照表

| 品牌 | 造车关键词 | 典型受众 | 补能 / 动力印象 | 资本市场标签 |
|------|------------|----------|-----------------|--------------|
| 理想 | 家庭、空间、省心 | 奶爸 / 多人口家庭 | 增程（纯电在补） | 曾盈利标杆，近况承压 |
| 小鹏 | 智驾、科技 | 尝鲜中产、技术党 | 纯电 + 快充 | 成长股，波动大 |
| 蔚来 | 服务、换电、社群 | 中高净值 + 多品牌下沉 | 换电网络 | 故事长、兑现慢 |
| 小米 | 颜值、生态、性价比运动 | 年轻用户 → 家庭扩展 | 纯电为主，增程在路上 | 集团估值里的弹性项 |
| 特斯拉 | 平台、软件、全球 | 全球科技用户 | 超充 + 纯电 | AI 溢价型巨头 |

## 三、港股 / 美股近几年走势：低谷还是高估？

> 下列价格为 **约 2026 年 7 月上旬** 公开行情的量级，仅供建立坐标。

### 1. 价格坐标（约数）

| 标的 | 代码 | 近况量级 | 长周期位置感 |
|------|------|----------|--------------|
| 理想 | LI | 约 **12 美元**；52 周约 **11.7–32** | 相对 52 周高位大幅回撤，靠近区间下沿 |
| 小鹏 | XPEV | 约 **13 美元**；52 周约 **11.8–28** | 2025 年曾修复，2026 年再度回吐部分涨幅 |
| 蔚来 | NIO | 约 **4.8 美元**；52 周约 **4–8** | 相对 2021 年高峰（60 美元级）仍是 **深度熊市区间** |
| 特斯拉 | TSLA | 约 **400+ 美元**；市值约 **1.5 万亿美元** 量级；52 周约 **300–500** | 远高于传统车企估值中枢，处历史高估值带 |
| 小米集团 | 1810.HK | 随手机景气 + 汽车叙事剧烈波动 | **不是纯车股**；汽车是期权也是扰动项 |

新势力 ADR 在 2021 前后享受过流动性与赛道泡沫；2022–2024 年经历 **加息 + 价格战 + 盈利证伪** 的杀估值；2025 部分标的因销量与智驾预期反弹，**2026 年又因竞争与盈利节奏再度分化调整**。

### 2. 怎么判断「低谷」还是「高估」？

**（1）相对自身历史**  
- **蔚来、理想、小鹏**：相对 2021 年泡沫顶，多数仍处 **估值与情绪的相对低位**；但不等于「低估」——低位可以是价值，也可以是价值陷阱。  
- **特斯拉**：相对传统车企永远偏贵；相对自身，则取决于市场是否继续给 AI / Robotaxi 高权重。

**（2）相对基本面（最重要）**  
问四个问题：
1. **销量是否有产品周期支撑？**（下一代爆款是否清晰）  
2. **毛利率与经营杠杆是否改善？**（价格战是否见底）  
3. **现金与融资能力是否安全？**（尤其重资产换电、扩产）  
4. **故事是否已过度提前计价？**（智驾、机器人、海外）

**（3）相对可比公司**  
- 已规模化且接近或已经盈利的自主品牌，往往用 **更克制的市销率 / 市盈率**。  
- 仍在亏损的新势力，市场给的是 **期权定价**：智驾领先一点、出口突破一点，弹性就大；一旦季度交付 miss，杀估值也快。

### 3. 分标的的直觉结论（主观框架，非评级）

| 标的 | 更像什么状态 | 理由（简化） |
|------|--------------|--------------|
| **理想 LI** | **情绪与预期的相对低谷，基本面需观察反转** | 股价靠近 52 周低位，反映竞争与增长担忧；若新品与毛利修复被验证，弹性来自预期修正，而非「已经很便宜所以必涨」 |
| **小鹏 XPEV** | **高波动成长股：叙事与交付博弈** | 智驾与出口给过溢价，盈利尚未成为稳定锚；当前位置更像「定价分歧大」，不是单边高估或低估 |

## 四、给自己的研究 checklist

以后再看这个行业，可以按下面清单快速扫一遍：

1. **行业**：当月渗透率、均价、库存、以旧换新执行力度  
2. **供应链**：碳酸锂与电池报价、头部电池排产、账期与质保纠纷新闻  
3. **公司**：批发 / 零售 / 交付口径是否一致；新车周期；毛利率；经营现金流  
4. **竞争**：同一价格带谁在放量（家庭 SUV、20 万级轿车、高端纯电）  
5. **政策**：购置税阶段、双积分、智驾宣传与数据合规  
6. **股价**：是交易「下季度交付」还是交易「三年后 AI」——两者止盈止损逻辑完全不同

## 五、收束

新能源汽车已经不是「买不买电动车」的问题，而是：

- **供应链** 决定成本与质量上限；  
- **产品定义** 决定你打哪群人、赚不赚得到毛利；  
- **补能与软件** 决定有没有第二曲线；  
- **政策** 提供斜坡而不是电梯；  
- **资本市场** 则在「周期低位」与「故事溢价」之间反复横跳。

对理想、小鹏、蔚来、小米、特斯拉：  

- 理想 = 家庭确定性；  
- 小鹏 = 智驾技术；  
- 蔚来 = 服务与换电；  
- 小米 = 生态与年轻运动切入；  
- 特斯拉 = 全球平台 + AI 叙事。  

2026 年中回看股价：中国新势力整体更接近 **泡沫后的再定价与分化**，局部标的呈现 **情绪低谷**；特斯拉则仍在 **高估值带** 上交易未来。是否「值得买」，取决于你的持有期、对盈利兑现的信念，以及对「汽车是否被重新定义为机器人」的判断——那已超出一篇行业通识笔记的范围，留给之后的跟踪更新。
